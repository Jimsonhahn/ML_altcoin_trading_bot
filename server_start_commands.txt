🚀 WINDOWS SERVER DEPLOYMENT COMMANDS
=====================================

## 1. Upload auf Windows Server:
Run PowerShell auf dem Windows Server (85.215.183.30):

```powershell
# Navigate to deployment directory
cd C:\Users\Administrator\Ml_altcoin_trading_bot\server

# Start Dashboard API Server
python dashboard_api.py
```

## 2. Server wird verfügbar unter:
- Local: http://localhost:5000
- External: http://85.215.183.30:5000

## 4. Test Commands für Server:

## 5. Firewall Configuration (if needed):
```powershell
# Allow port 5000 through Windows Firewall
New-NetFirewallRule -DisplayName "Trading Bot Dashboard" -Direction Inbound -Port 5000 -Protocol TCP -Action Allow
```

## 6. Production Server Commands:
```powershell
# For production deployment
python -m gunicorn --bind 0.0.0.0:5000 --workers 1 server.dashboard_api:app
```
