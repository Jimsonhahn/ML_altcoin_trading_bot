## 🚀 **DEPLOYMENT SCHRITTE FÜR STRATO WINDOWS SERVER:**

### **SCHRITT 1: Connect to Server**
```
1. Remote Desktop Connection öffnen
2. Server: 85.215.183.30
3. Username: dministrator (dein aktueller Username)
4. Login via RDP
```

### **SCHRITT 2: Create Directory**
```
Auf dem Windows Server in PowerShell:
mkdir C:\TradingBot
cd C:\TradingBot
```

### **SCHRITT 3: Copy Files**
**Kopiere ALLE diese Dateien von deinem Mac zu C:\TradingBot\ auf dem Server:**

**Core Python Files:**
- `main.py`
- `core/enhanced_decision_logger.py` 
- `api/routes/intelligence.py`
- `run_intelligence_api.py`
- `start_enhanced_bot.py`
- `mobile_dashboard.html`

**All other directories:**
- `strategies/` (komplett)
- `config/` (komplett)  
- `utils/` (komplett)
- `data_sources/` (komplett)
- `ml_components/` (komplett)

**Windows Scripts:**
- `install_dependencies_windows.bat`
- `start_bot_windows.bat`
- `stop_bot_windows.bat` 
- `status_bot_windows.bat`

**Config Files:**
- `requirements_simple.txt`
- `.env_simple_example`

### **SCHRITT 4: Install Dependencies** 
```
Auf dem Windows Server:
Double-click: install_dependencies_windows.bat
```

### **SCHRITT 5: Configure Environment**
```
1. Copy .env_simple_example to .env
2. Edit .env with your real API keys:
   BINANCE_API_KEY=your_real_key
   BINANCE_SECRET_KEY=your_real_secret
   TRADING_MODE=live (for real money!)
```

### **SCHRITT 6: START THE MONEY MACHINE!** 🚀💰
```
Double-click: start_bot_windows.bat
```
